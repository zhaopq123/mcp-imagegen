# 快速开始

从零到跑通，约 5 分钟。

---

## 前置条件

| 项 | 要求 |
|---|---|
| Python | ≥ 3.10（实测 3.12 最佳）|
| Agnes API Token | 从 [Agnes AI](https://api.agnes-ai.cn) 获取 |
| 网络 | 能访问 `api.agnes-ai.cn` |

---

## 第 1 步：获取代码

```bash
git clone https://github.com/zhaopq123/mcp-imagegen.git
cd mcp-imagegen
```

> 国内用户可用 Gitee 镜像：`https://gitee.com/zhaopq/mcp-imagegen.git`

---

## 第 2 步：装依赖

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

> **Windows** 用 `venv\Scripts\pip.exe` 代替 `./venv/bin/pip`

依赖只有三个：`fastmcp` / `httpx` / `uvicorn`（版本已钉死，见 requirements.txt）。

---

## 第 3 步：配置

```bash
cp config.example.env .env
```

编辑 `.env`，**至少填这两项**：

```bash
AGNES_TOKEN=你的Agnes密钥
MCPACCESS_TOKEN=自己定一个强随机串
```

`MCPACCESS_TOKEN` 是**客户端访问你这个服务时要带的密码**，自己随便定，
比如用 `openssl rand -hex 32` 生成一个。

> ⚠️ 这两项缺失会导致启动直接失败（退出码 2）——这是刻意的 fail-fast 设计。

---

## 第 4 步：自检

```bash
./venv/bin/python server.py --check
```

**期望输出**：

```
[config] 嵌套不等式自检: read ≤ 分档(max=60s) ≤ deadline(200s) < Agent建议(210s) < TimeoutStop(220s) ✓
[config] 队列等待 30s ≤ 总预算 ✓ | persist 下载 图30s/视频120s ≤ 总预算 ✓ | 并发槽 3 | 熔断 硬600s/软300s
[startup] 配置自检通过（--check）
```

退出码 `0` = 通过，`2` = 配置有问题（会打印具体原因）。

---

## 第 5 步：运行

```bash
set -a; . ./.env; set +a
./venv/bin/python server.py
```

看到这些就成功了：

```
[startup] 就绪 port=8000 image_dir=/var/lib/mcp-imagegen/images ...
INFO:     Uvicorn running on http://0.0.0.0:8000
```

---

## 第 6 步：验证

**另开一个终端**，测健康检查：

```bash
curl http://127.0.0.1:8000/healthz
# 期望: {"status":"ok"}
```

测鉴权是否生效（不带 token 应该被拒）：

```bash
curl -i http://127.0.0.1:8000/mcp
# 期望: HTTP/1.1 401 Unauthorized
```

---

## 第 7 步：接入你的 AI 客户端

见 → [接入客户端](接入客户端)

最短路径（通用 JSON 格式，多数客户端适用）：

```json
{
  "mcpServers": {
    "mcp-imagegen": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:8000/mcp",
      "headers": {
        "Authorization": "Bearer 你的MCPACCESS_TOKEN"
      },
      "timeout": 240000
    }
  }
}
```

> ⚠️ **timeout 一定要设够**（建议 240000 毫秒）。因为视频生成要 5–10 分钟，
> 默认超时短的客户端会提前断开。
