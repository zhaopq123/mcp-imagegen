# 常见问题

部署和运行中踩过的坑，按现象分类。

---

## 启动相关

### 启动直接退出，退出码 2

**原因**：配置自检失败（fail-fast 设计）。

看输出里 `[startup] 配置自检失败:` 那行，会列出具体问题：
- `必填环境变量缺失: MCPACCESS_TOKEN, AGNES_TOKEN` → 没填密钥
- `环境变量 MAXCONCURRENCY=abc 无法解析为 int` → 类型写错
- 嵌套不等式违例 → 超时配置改坏了，看提示修正

### 报 `ModuleNotFoundError: No module named 'fastmcp'`

依赖没装进 venv：

```bash
./venv/bin/pip install -r requirements.txt
```

### fastmcp 装不上 / 导入报 `IdentityAssertionParams`

**别装 2.14.3**。它声明的依赖与实际 import 不符，在当前 PyPI 依赖树下装不上。
用 `fastmcp==4.1.0`（requirements.txt 已钉死）。

## 运行相关

### 客户端报 401 Unauthorized

`MCPACCESS_TOKEN` 不对。检查三处：
1. 客户端 headers 里是否带了 `Authorization: Bearer <token>`
2. **Bearer 后面有个空格**，别漏
3. 服务端 `.env` 里的值和客户端填的是否一致

改了 `.env` 后要**重启服务**才生效。

### 健康检查通，但调工具报连接失败

- 客户端超时设太短 → 调到 240000ms 以上
- 视频生成 5–10 分钟，超时短的客户端会提前断开

### 上游报 429（限流）或 402

Agnes 免费配额用完了或请求太频繁。
服务会自动进入**硬熔断**（600 秒），期间请求立即返回 `upstream_error retry=yes`。

**等熔断结束再试**，或者升级 Agnes 套餐。不要手动高频重试——那会让熔断一直续期。

### 上游报 503（队列满）

视频生成队列是上游的，满的时候提交会失败。
返回体里带 `retry=yes`，**稍后重试即可**。这是上游容量问题，不是本服务的 bug。

## 转存（persist）相关

### persist=true 但 /files 打不开

检查 `IMAGE_DIR` / `VIDEO_DIR` 目录：
1. 目录是否存在（启动时会尝试自建，失败会降级）
2. 进程对该目录**有写权限**

手动预建并授权：

```bash
sudo mkdir -p /var/lib/mcp-imagegen/{images,videos}
sudo chown -R $USER:$USER /var/lib/mcp-imagegen
```

### 转存失败，返回了上游临时 URL

返回里会带 `persist_failed` 标记。常见原因：
- 上游 URL 过期（转存也有超时）
- 磁盘满

不阻塞主流程——图片本身已经生成好了，只是没存到本地。

## 部署相关（无 systemd 环境）

### proot / 容器里 systemctl 用不了

正常——proot 没有 systemd。用 tmux 守护替代：

```bash
tmux new-session -d -s mcp-imagegen \
  "while true; do set -a; . /etc/mcp-imagegen/env; set +a; \
   exec /opt/mcp-imagegen/venv/bin/python /opt/mcp-imagegen/server.py; \
   echo '[ exited, retry in 10s ]'; sleep 10; done"
```

完整部署手册见仓库 `deploy/install.md`。

### 安卓手机上跑，息屏后断连

- 安卓会杀后台进程 → 需要 **Termux:Boot** + 唤醒锁（`termux-wake-lock`）
- 厂商省电策略 → 把 Termux 加入自启白名单、关闭电池优化

## Windows 相关

### 写 mcp.json 后客户端报 JSON 解析失败

**PowerShell 的 `Set-Content -Encoding UTF8` / `Out-File` 会写 BOM**，
很多解析器不认。正确写法：

```powershell
[System.IO.File]::WriteAllText($path, $json, (New-Object System.Text.UTF8Encoding($false)))
```

或者干脆用记事本/VS Code 手写（另存为 UTF-8 无 BOM）。

### git push 报 `Recv failure: Connection was reset`

`github.com:443` 被墙。国内网络需要代理，或用 Gitee 镜像。

## 其他

### 模型能换吗

能。改 `.env`：

```bash
AGNES_IMAGE_MODEL=新的模型ID
AGNES_VIDEO_MODEL=新的模型ID
```

留空用内置默认。上游出更名/新模型时不用改代码。

### 多个客户端能同时用吗

能。并发上限由 `MAXCONCURRENCY` 控制（默认 3），
超出的排队（最多等 30 秒）。多个 AI 客户端共用一个服务是典型用法。

### 数据会丢吗

- 转存的图片/视频：在磁盘上，**不丢**
- 视频任务表：内存态，**重启即失**（2 小时 TTL 内轮询完就不影响）
