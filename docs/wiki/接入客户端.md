# 接入客户端

MCP 端点：`http://<你的服务器IP>:8000/mcp`
传输类型：**streamable-http**
鉴权：Bearer Token（即 `MCPACCESS_TOKEN`）

> ⚠️ **各客户端的配置格式不通用**。类型字段、超时字段的写法各家不同，下面分开列。
> 共同点：**超时务必设够（建议 240000ms）**，视频生成要 5–10 分钟。

---

## Claude Desktop / 通用 JSON

```json
{
  "mcpServers": {
    "mcp-imagegen": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:8000/mcp",
      "headers": {
        "Authorization": "Bearer 你的MCPACCESS_TOKEN"
      },
      "timeout": 240000
    }
  }
}
```

---

## DSH（dsh-mcp-manager）

写 `<DSH_HOME>/@wingsky-1/dsh-mcp-manager/mcp.json`（全局），
或 `<项目根>/.dsh/@wingsky-1/dsh-mcp-manager/mcp.json`（项目级）：

```json
{
  "version": 1,
  "servers": [
    {
      "name": "mcp-imagegen",
      "transport": "streamable-http",
      "url": "http://127.0.0.1:8000/mcp",
      "headers": { "Authorization": "Bearer 你的token" },
      "toolCallTimeoutMs": 240000
    }
  ]
}
```

> 注意：类型写 `streamable-http`（连字符）；
> 超时字段叫 `toolCallTimeoutMs`；
> 传 JSON 时别用 PowerShell 的 `Set-Content -Encoding UTF8`（会写 BOM 导致解析失败），
> 用 `[IO.File]::WriteAllText($p, $json, (New-Object System.Text.UTF8Encoding($false)))`。

## 豆包工作

入口：左侧「插件·技能·伙伴」→ 插件页右上角 **+ 添加** → **自定义连接器**
（注意：叫"连接器"不是"插件"）

| 字段 | 值 |
|---|---|
| 服务器名称 | `mcp-imagegen` |
| 传输类型 | **HTTP** |
| 服务器 URL | `http://<IP>:8000/mcp` |
| 自定义 Headers | 名称 `Authorization`，值 `Bearer <token>` |

> **Headers 的值要连 `Bearer ` 前缀一起填**（含空格）。

---

## WorkBuddy

类型写 `streamableHttp`（驼峰），超时 240000：

```json
{
  "mcpServers": {
    "mcp-imagegen": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:8000/mcp",
      "headers": { "Authorization": "Bearer <token>" },
      "timeout": 240000
    }
  }
}
```

---

## 三家写法差异速查

| 客户端 | 传输类型写法 | 超时字段 |
|---|---|---|
| 通用/Claude | `streamableHttp` | `timeout`（毫秒）|
| DSH | `streamable-http` | `toolCallTimeoutMs` |
| 豆包工作 | `HTTP` | 界面里配置 |
| WorkBuddy | `streamableHttp` | `timeout`（毫秒）|

---

## 验证连通

接好后，在客户端里问 AI：

> 帮我画一张图：一只橘猫趴在木桌上晒太阳

- ✅ 约 10 秒返回图片 URL → 成功
- ❌ 401 → token 不对（检查 Bearer 前缀）
- ❌ 连接失败 → 检查 IP 和端口
- ❌ 超时 → 检查 timeout 是否设够

## 局域网访问

服务监听 `0.0.0.0`，局域网内其他设备可直接访问：

```
http://<服务器局域网IP>:8000/mcp
```

> 安全提醒：这是明文 HTTP，仅建议在内网使用。
> 若需公网暴露，前面加 Caddy/Nginx 做 HTTPS（见仓库 deploy/Caddyfile）。
